# 河海抢课器

针对 `jwxt.hhu.edu.cn`（强智 jsxsd / 河海统一身份认证）的选课辅助工具。
真实浏览器登录 → 拉取可选课程 → 网页勾选入队 → 逐门排队抢课。

## 环境

需要 Python 3.8 以上，依赖两个库：

```bat
python -m pip install -r requirements.txt
python -m playwright install chromium
```

`start.bat` 首次运行会自己检测并装好，装过就跳过，一般不用手动执行。

pip 直连慢或报错时换国内源：

```bat
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

第二个命令装的是 Playwright 的浏览器内核。没装也能跑——本机装了 Edge 或 Chrome
就用它们，脚本会优先挑这两个，都没有才回落到 chromium。

## 启动

双击 `start.bat`，或：

```bat
cd 本目录
set HHU_ACC=学号
python xk_runner.py --port 8899
```

密码不落盘。首次运行会提示输入，或事先 `set HHU_PWD=...`。
浏览器会自动打开 `http://127.0.0.1:8899/`。

常用参数：

| 参数 | 说明 |
|---|---|
| `--port 8899` | 控制台端口 |
| `--interval 0.5` | 到点后的抢课轮询间隔（秒） |
| `--round-every 1` | 等选课轮次放出来的查询间隔（秒） |
| `--headless` | 登录时不弹浏览器窗口 |
| `--no-browser` | 不自动打开控制台 |
| `--acc / --pwd` | 直接给账号密码 |

## 抢课节奏

入队的课排成一条队列，同一时刻只有一门在提交。一门课占住队头一段时间还没
结果，就回队尾重排，让后面的课也轮到——不然排在后面的课一发请求都发不出去。

抢课靠的是有耐心地反复问：教务放出一个名额，谁下一个轮询撞上就是谁的。

脚本内部对同一会话的请求做了统一节流，`--interval` 往下调不会真的把请求
压密。这是有意的：教务对短时间内的高频提交会拦，触发风控之后这门课就得
等下个时段了。压着节奏跑，命中率反而高。

选课未开放时按 3 秒一轮慢跑，到开抢时刻自动切到 `--interval` 的节奏，
并重拉一次类别和课程（预览期的入口和正选期不是同一套）。

## 界面

左栏是可选课程，顶部的类别标签按本轮实际开放的选课类别自动生成（公选课、体育课、
本专业选课、跨专业选课……有什么显示什么），支持关键词、只看有余额、排除冲突。
下面一行「课程类别」按课程自身的分类筛（通识劳动教育、数智素养能力类…… / 体育项目），
跟着上面选的选课类别联动。勾选后点右上「加入队列」，或点行尾的「抢」单个入队。

时间和地点是多行显示的，一门课多个时段会一项一行，不再截断。

课程表里「学分」单独一列，教务没给学分的班显示 `—`。勾选课程后左下角会显示
「已选 N 门 · X 学分」，队列标题也带学分合计——失败和错误的课不计入，待命、
抢课中、已抢到、已完成、已停止的都算，方便对着学分上限估。

右栏是队列和实时日志。队列卡片显示状态（待命 / 抢课中 / 已抢到 / 失败）和每次服务端的回话。

顶栏「体育积分」和「选课志愿」两个框：体育课是志愿制，填了积分就会带 `trjf`
参数一起提交；部分轮次按志愿提交，填了志愿就会带 `xkzy`。两个都留空就不填。

## 行为

- 启动时从选课入口页解析本轮开放的选课类别，逐个拉课程；解析不到就用内置的公选课 / 体育课兜底。
- 每类课程的列表接口、查询串、列定义、提交接口都按页面里的实际配置走——公选课提交到 `ggxxkxkOper`，体育课提交到 `bxxkOper`，不是同一个口子。
- 队列写进 `queue.json`，关掉程序再开会自动恢复并继续抢。
- 「停止」只是暂停，点「恢复」把停下来的任务重新丢回引擎继续抢；「移除」和「清理」
  是真删掉，删了得回去重新勾选入队。
- 抢到（`success:true`）或撞上硬性拒绝（冲突、学分不符、限选）会自动停止该任务并记日志。

## 排错

**报 ModuleNotFoundError: No module named 'requests'（或 playwright）？**
依赖没装，补一条 `python -m pip install -r requirements.txt`。

**登录时报「无法启动浏览器」？**
Playwright 内核和本机浏览器都没找到。装 Edge/Chrome，或执行
`python -m playwright install chromium`。

**日志里没有「本轮选课类别」这行？**
说明入口页没解析出来，会退回内置清单。先点一次「刷新课程」；还不行就把
`--port` 指到的页面截图发出来看。

## 注意

- **别重复启动**。端口被占时会直接报错退出，不会两个窗口打架。界面没变化时先看看
  是不是还开着旧的那个窗口，关掉再开。
- 登录会话存在 `session_state.json`，服务端一般几小时到几天失效。脚本会自动检测，
  失效后重新运行输入密码即可；会话还有效时不会再问学号密码。
- 密码只在登录那一刻交给本机浏览器，不写入任何文件。
- 这是辅助工具，最终以教务系统实际结果为准。
